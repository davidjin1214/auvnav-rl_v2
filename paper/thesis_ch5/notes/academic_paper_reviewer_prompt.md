# §5.1/§5.2 审查 — 新对话启动 Prompt（academic-paper-reviewer）

> 用法：新开对话整段粘贴。首条指令即以多审稿人模式评审已成稿的前两节。
> 与 `ars_full_review_prompt.md`（ars-full 版）并排，二选一：本版是**纯对抗式同行评审**（多审稿人 + 交叉综述，不触碰正文），护栏更稳、噪音更少。

请使用 `/academic-research-skills:academic-paper-reviewer` 的**完整评审模式（full review）**，评审我博士论文第 5 章已成稿的前两节——**§5.1 引言**、**§5.2 研究背景与定位**——维度包括但不限于**结构、内容、论证、定位、学术分量、语言表达、引用忠实度**。

## 任务性质

- 这是**同行评审**：产出审稿报告，**不改写正文、不编辑任何文件**（包括 `refs.bib`）。具体修改建议交我，由我决定是否落地。
- 评审对象是经多轮打磨的成稿（已编译，6 页，0 undefined）；请给诚实、苛刻、可操作的意见，不要客套。

## 建议的审稿人构成（供 skill 配置 field-specific personas）

- **R1 — 离线/深度强化学习方法专家**：评判中心命题是否严谨、offline-RL 与特权学习定位是否到位、术语是否专业准确。
- **R2 — 水下机器人 / AUV 运动规划与海洋自主专家**：评判部署现实性、单点传感与任务设定的刻画、生物借流类比是否得当。
- **R3 — 中文学术写作 / 学位论文语体审稿人**：评判 register、结构、语言表达、句法节奏、有无翻译腔/汇报体残留。
- **Devil's Advocate**：专攻三处软肋——(a) gap 是否只是"组合空白"而缺乏 consequentiality；(b)"不提出新算法、贡献为科学洞见"是否撑得起核心贡献章的分量；(c) 两条主线（时序利用 / 目标-数据适配）是否真正统一、还是被一句口号拼接。
- **EIC / 答辩主席**：综合显著性、连贯性，判断这两节是否读起来像高水平博士论文的核心贡献章开篇。

## 被审对象与文件

- §5.1：`paper/thesis_ch5/sections/intro.tex`
- §5.2：`paper/thesis_ch5/sections/related_work.tex`
- 章工程 / 9 节序：`paper/thesis_ch5/main.tex`
- 写作 spec（设计依据；§0.4 红线 / §0.5.9 register / §0.5.10 术语规范 / §1 骨架 / §2 逐节映射）：`paper/thesis_chapter_outline.md`
- 数字 ground truth（核对事实性 claim，勿凭记忆）：`docs/rebrac_experiment_report.md`、`docs/offline_rl_line_summary.md`
- 生物/RL 借流综述底本（核引用转述忠实度）：`reference/flow_navigation_rl_review_zh.md`

## 重要语境（避免误判扣分）

- 这是 9 节章的**前两节**（引言 + 研究背景与定位）。§5.3–§5.9（问题设定 / online 可学性 / 离线基线 / ReBRAC 主线 / 边界 / 算法对比 / 讨论）**尚未起草**。**不要**因"缺方法、缺结果、缺实验数字、未见贡献的实证"而扣分——那些属后续节。
- **中心命题（已锁定，全章统一）**：在部署约束下，提升性能的关键在于**用好已有的信息与数据**，而非**为系统增添能力**。前者落实为两条途径——单点观测的时序利用、模仿目标与数据质量相适配；后者——更多空间传感器 / 向价值网络注入特权观测 / 更强生成式先验——则或非必需、或不普遍有效。

## 以下为有意决策，非缺陷

常规审稿意见请**勿**把下列条目当错误。**但 Devil's Advocate 可（并被鼓励）正面挑战它们**——若认为某条损害作品，单独成栏、给出理由，我另行判断：

1. **零跨章引述**：引言/背景不点名邻章（前一章是不同范式的全局路径规划）。
2. **生物（借流）只作引子**：§5.1 ¶1 起兴 + §5.2 ¶1/¶2 landscape，刻意不反复回扣。
3. **贡献是科学洞见、非新算法**；正文**不写"本章不提出新算法/方法均为已有"这类反向宣告**。
4. **抽象下界**：引言贡献层不出现 涡街 / REMUS-100 / DVL / ReBRAC / FQL 等具体专名（留后续节）。
5. **§0.4 机制归因红线**：critic LayerNorm 不进"可有可无"清单；空间传感器写"非必需"而非"无用"；更强先验"不普遍有效"只主张方向、不主张幅度；引言不带实验数字。
6. **术语规范（spec §0.5.10）**：不用 teacher（本章无蒸馏关系）；off-policy→异策略；actor/critic 裸名词→策略网络/价值网络；不用 旋钮/headline/anchor 名词。

## 输出要求

- **每位审稿人**：独立 referee report，问题按 **CRITICAL / HIGH / MEDIUM / LOW** 分级，每条标注定位（节/段/句）并给可操作修改方向。
- **引用忠实度**：对照综述底本核转述，关键著录可联网核验，指出错配/可疑遗漏（但不改 bib）。
- **交叉综述（cross-review synthesis）**：合并去重各审稿人意见，标出**分歧点**与**共识必改项**。
- **EIC 裁决**：给总体判断——距离"高水平中文博士论文前两节"的差距 + 排序后的改进优先级（注明哪些属"约束内改进"、哪些属 Devil's Advocate 的"挑战既定约束"）。

先读上述 spec 与两节正文，再开始评审。
