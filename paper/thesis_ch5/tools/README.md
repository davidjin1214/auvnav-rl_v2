# `paper/thesis_ch5/tools/` — 第 5 章机械门槛复核工具

> 收入时间：2026-07-28（收尾统稿轮）。此前这批脚本只活在临时目录里，跑完即失；而 spec §0.5.9 (d) 要求语体计量口径「可复现」——**脚本才是口径最可复现的形式**，散文规则与实现放在两处必然漂移。本目录即该口径的可执行副本。

## 为什么需要它

第 5 章有一类反复出问题的声明：**版面与计量类结论会随任意一次文本改动失效，但它们看上去像事实、会被后续几轮直接引用。**

- 2026-07-08 曾声明「全部浮动距首引 0–2 页」「图表编号与首引序全章对齐」「编译 58 页」。该声明被三轮 prompt 沿用，到 2026-07-28 实测为**浮动越线 4 处、编号序逆序 1 处、63 页**——三项全错，其中编号逆序此前从未被任何一轮报出。
- 三轮复审各自实现了一套破折号密度口径，报出 0.635／0.618／0.593，**分子完全一致、分母互不相容**，事后无法相减、甚至不能假定同源（findings §12.1）。

**规矩：任何版面或计量数字，引用前重跑，不要引用历史结果。**

## 用法

Python 用 conda env `mytorch1`（本机 `C:\Users\jinxiang\miniconda3\envs\mytorch1\python.exe`；非交互 shell 里 conda 不在 PATH）。全部脚本从自身位置推导路径，**在任何工作目录下都能跑**，无硬编码绝对路径。

```bash
# 前置：必须有当前构建。latexmk -c 会删掉 main.aux，故须在复核之后再清。
cd paper/thesis_ch5
latexmk -pdf -xelatex -interaction=nonstopmode main.tex

# 一键门槛复核（退出码 0 = 全过）
python tools/ch5_check_all.py

latexmk -c
```

| 脚本 | 作用 | 判据 |
|---|---|---|
| `ch5_check_all.py` | 汇总下列各项 ＋ 编译门槛（undefined／multiply／Overfull>10pt／bibtex warning／页数） | 全 PASS |
| `ch5_metrics.py` | 语体计量：破折号密度、段落句数、最长句、caption 长度 | **无判据——诊断读数** |
| `ch5_floats.py` | 浮动落位距首引页数 | ≤ 2 页 |
| `ch5_order.py` | 图表编号序 vs 首引序 | 零逆序 |
| `ch5_lexcheck.py` | 禁用词表、术语四档、报告体 marker、引号、英文括注首现 | 与已裁定基线零差异 |
| `ch5_refs.py` | 每个 `sec:`/`subsec:` 交叉引用解析到真实标题 | 零未解析 |
| `_ch5_corpus.py` | 共享语料加载器 = spec §0.5.9 (d) 九条口径的实现 | — |

本目录另有一类**证据类工具**，不进 `ch5_check_all.py`、不是门槛，而是把某个刊出数字的来路做成可重跑的一条命令（判据一律是「复算值与刊值对得上」）。它们各自服务一次具体的核查，用完不删——下次有人质疑同一个数字时，重跑比重新考古便宜：

| 脚本 | 核的是什么 |
|---|---|
| `ch5_dispersion_audit.py` | 全章 $\pm$ 的离散度口径；能由行内逐种子值自解的逐处判 ddof，`--convert` 打印换算后的值 |
| `ch5_sac_ladder_dispersion_check.py` | §5.9 SAC 阶梯表那 $12$ 处的口径（行内不印逐种子值，只能回 `results/` 逐 run 复算） |
| `ch5_holdout_split_audit.py` | 把已刊的 $100$ 回合读数拆成参与选点的 $40$ 与留出的 $60$，仅在后者上重算组间比较 |
| `ch5_clean_probe_readout.py` | 训练／评估实例重合的抬升量（干净 manifest 补评的差中差） |

常用变体：

```bash
python tools/ch5_metrics.py --top 20                          # 更长的最长句清单
python tools/ch5_metrics.py --baseline 8cd9160 bbffb98        # 用本脚本重测 git 基线，出趋势表
python tools/ch5_lexcheck.py --full                           # 每一处命中 + 上下文
python tools/ch5_refs.py                                      # 逐条引用 + 目标标题 + 引用处语境
```

## 两条使用纪律

**一 · 计量是诊断读数，不是门槛。** spec §0.5.8（用户拍板的最高写作原则）禁止预设页数、cite 数与段落长度的量化目标；§0.5.9 (d) 对这些数字再申明一次。具体地：

- §5.7–§5.10 破折号密度高于前六节，是**论证类型差**——那几节正是承载口径隔离、种子与配置限定、scope 句的节，而中文里这些成分的标准载体就是破折号。2026-07-28 逐处清点后四节 100 个破折号，未见一处是可删的插入语堆叠。
- §0.5.7「每段 3–4 句封顶」已降格为**诊断触发器**。触发后正确的动作是问一句「这段是不是在做两件不同的论证动作」，而不是拆。反例就在收尾统稿轮：§5.8.m 的初版拆段为迁就 4 句而把「差异有三处」的第三处切到下一段，被定点复核判为**导航性退化**。
- **绝不以删减或压缩口径声明、锁定措辞、scope 句、种子与配置限定来改善任何一项数字。** 臃肿处**改写而非删除**，且须逐句对照说明哪些成分保留了。

**二 · `--freeze` 是断言，不是消警告开关。** `ch5_lexcheck.py` 的基线（`ch5_lexicon_baseline.json`）记录「已裁定为合规」的命中分布，此后只报增量。冻结即断言**当前每一处命中都已逐条裁定并记入 findings ＋ spec §0.5.11 豁免行**。

这个机制针对的是一次真实事故：本章禁用词命中绝大多数合规（「相当比例」是量词、「不作等价判断」是否定式、「无差异」六处属 §5.9.1 预登记矩阵判读），每轮重新论证一遍，反而让真命中藏在里面——2026-07-28「§5.7.1 是全章唯一的规则②漏网」这句话被写进四份文档，而支撑它的检索**只穷举了规则②五个词中的一个**（findings §12.9 教训 2）。

## 机器验不了的部分

`ch5_check_all.py` 全 PASS **不等于**本章合格。以下仍是人的活：

- `\ref` 指向的是不是**恰当**的小节（`ch5_refs.py` 把「引用处语境 ↔ 目标标题」并排打出来，供人读）
- 禁用词命中的**语义裁定**（规则②的判据见 spec §0.5.11：管的是**幅度类零结果**；**离散配置事实**不在射程内，但所指须写成可直接观测的形式）
- **数字忠实度**——一律回查 ground truth，禁止凭记忆、禁止以 `.tex` 头注或成稿自述为准
- **反向 churn**——有无口径声明、锁定措辞、scope 句、种子与配置限定被削弱
